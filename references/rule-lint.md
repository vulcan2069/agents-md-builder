# Rule Lint

生成前逐条检查，未通过就改写或删除。

1. **具体：** 有触发条件或适用范围吗？
2. **可执行：** 是否明确写出 Agent 的动作？
3. **可观察：** 能否从一次实际任务判断是否遵守？
4. **来源可靠：** 来自用户回答/确认，或已说明的核心原则吗？
5. **无冲突：** 是否与其他规则或用户回答矛盾？若有，回到用户确认，不自行选择。
6. **不重复：** 是否已被另一条更具体的规则覆盖？
7. **有行为影响：** 删除这条会不会让 Agent 行为改变？不会就删除。
8. **适用：** 对用户的工作方式真的有用吗？
9. **简洁：** 能否用更少的字保留相同约束？
10. **空话清除：** 删除“写高质量内容”“遵循最佳实践”“保持专业”“认真思考”“让用户满意”等无法判断的句子。

另外检查：权限已由用户逐项确认；不相关章节已移除；没有未填写占位符；没有把案例资料或推测当成用户事实；正文长度符合“有用优先于完整”。
