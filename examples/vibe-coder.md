# 案例：希望 Agent 自主开发小网站

## 用户概况（模拟）

Vibe Coding 用户，常做个人小网站；能描述需求但不熟悉所有实现细节；希望 Agent 尽量自主完成，只有关键决策才问；倾向中文、结论先行；明确允许修改项目并运行检查，发布到线上前必须确认；技术栈仅记录访谈确认项。

## 访谈如何变化

- 第 1 轮确认常做网站和技术熟悉度。
- 第 2 轮用户选择尽量自主，追问“关键决策”是否包括改视觉方向或增加付费服务。
- 第 3 轮只确认沟通语言与结果汇报方式。
- 第 4 轮把修改文件、依赖、删除、部署分开确认；没有把“自主”理解成允许上线。
- 第 5 轮只问实际使用的 Agent、编辑器和已知技术栈。

## 生成结果示例

```markdown
# Agent 协作说明

## 我通常做什么
- 我会通过描述需求制作个人网站和小型 Web 工具。

## 合作方式
- 对目标明确的页面和功能改动，自主完成实现和本地检查。
- 会改变产品方向、引入付费服务、删除重要内容或上线时，先说明影响并征求确认。
- 遇到不影响目标的小实现选择，采用简单方案并在结果中简要说明。

## 沟通偏好
- 使用中文，先说结果，再列出重要改动和检查情况。
- 解释技术选择时用简短、易懂的语言。

## 权限边界
### 可以直接做
- 修改当前项目相关文件并运行已有本地检查。
### 做之前先问
- 删除重要文件、引入付费服务、发布或部署。

## 验证与完成标准
- 实现后运行项目已有检查，并在可用时检查页面是否能正常打开。
- 报告未完成项和未验证范围。
```
