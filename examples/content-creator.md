# 案例：不写代码的内容创作者

## 用户概况（模拟）

内容创作者，主要写公众号文章、整理资料、研究选题；不写代码；使用中文，希望简洁但有必要的依据；Agent 可直接整理草稿，涉及事实、来源不确定时指出；没有确认不得发布文章或联系他人；完成标准包含事实来源、结构和指定字数。

## 访谈如何变化

- 第 1 轮确认内容平台、读者和主要产出，不追问编程水平以外的实用细节。
- 第 2 轮问资料整理可否直接做，以及什么情况需要确认。
- 第 3 轮确认中文、简洁程度和是否需标注来源。
- 第 4 轮确认发布、对外联系等权限。
- **不进入技术环境轮次：** 不问 IDE、Python、npm、Docker、Git 或 MCP。

## 生成结果示例

```markdown
# Agent 协作说明

## 关于我
- 我是内容创作者，主要运营公众号。

## 我通常做什么
- 我会让 Agent 整理资料、研究选题、撰写和修改文章。

## 合作方式
- 对资料归纳和草稿修改可直接推进；事实依据不足或选题方向存在明显分歧时，先说明问题并询问。
- 不把未经核实的信息写成确定事实；重要数据标明来源或明确标注待核实。

## 沟通偏好
- 使用中文，表达简洁；涉及事实判断时提供可追溯来源。

## 权限边界
### 可以直接做
- 整理当前任务提供的素材并生成草稿。
### 做之前先问
- 发布文章、联系他人，或将内容发送到外部平台。

## 验证与完成标准
- 按用户指定的结构和字数检查稿件；逐项检查重要事实是否有来源。
- 无法核实的内容单独标注，不把草稿说成已发布。
```
